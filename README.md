# Spore 孢子 · 截图问答

Alt+S 框选截图 → 网页右缘自动弹出抽屉 → **先快答，再联网核实** → 答完右下角弹通知。

一个零构建的 Chromium/Edge MV3 扩展：不依赖本地服务、不依赖 npm 包，装上就能用。

## 用法

| 操作 | 说明 |
|---|---|
| `Alt+S` | 框选截图（先冻结当前视口，再拖出矩形，`Esc`/右键/单击取消） |
| 左上角半圆小角 | 展开时半圆**压在面板上**（`›`，点它收回）；收起后半圆**翻到面板之外**、凸在屏幕右缘（`‹`，点它弹出）——同一个元件用 `left + border-radius` 过渡翻面 |
| 圆形气泡 `💬`（抽屉内） | **点击**弹出会话列表（悬停不触发；点空白或再点气泡收起）；**抽屉收起时不显示**（抽屉里的东西只有拉开才看得见），红点 = 该会话有你没看过的结果 |
| `★`（抽屉顶栏，气泡右边） | **收藏当前会话**：再点一次取消，并弹「已收藏 / 已取消收藏」提示。星色自己给——收藏=品牌粉 `#ec4899`、未收藏=灰（用字符 ★ + `color`，**不交给系统 emoji 上色**，实测有机器把 ⭐ 渲染成黑色）；收藏**只标记不置顶**（置顶会把最新会话埋掉），要只看收藏去整页审查里筛。列表行左侧的 ★ 悬停即现，点它同样只切收藏（不会顺手打开该会话） |
| `↻` | 出错/中断时才出现，重跑这一问 |
| `Alt+Z` | 弹出/收起抽屉（manifest 默认绑定 + 页面内 keydown 兜底，双通道 600ms 去重）；设置页「快捷键」卡可隐藏**收起态**的半圆小角（只在收起时不遮网页，展开后的收起把手始终保留；默认露） |
| 列表行 `×` | 删除会话：**同时删磁盘镜像的 md/截图并刷新 `_index.md`**（仅静默目录模式；回落下载的文件浏览器删不了）；删除的是当前会话时自动加载最近会话 |
| 点抽屉之外 | 直接收起（框选截图期间、正在选中文字时不误收） |
| 列表行 `✎` | 弹**侧边栏内居中**的重命名框（与删除同构），回车即存 |
| 列表行 `×` | 弹**侧边栏内居中**的确认框（抽屉的子组件），Esc/点遮罩/「取消」都不会删 |
| 底部输入框 | 每个会话都能接着追问（Enter 发送，Shift+Enter 换行）。追问**随时可调检索工具**：说「再查一下」它就真的联网去查（`web_search` / `web` 与阶段B 同一套循环），不会回「我查不了」 |
| 右下角 `↓` | 手动回到最新（流式生成时不会自动滚） |
| 工具栏 `⚙` | **主页**（原设置页，标签页标题就叫「Spore 主页」）：左边索引第一项是「搜题记录」、与下面四张应用设置卡之间留了间距；右边仍是分页（模型 / 磁盘镜像 / 快捷键 / 日志） |
| 索引「搜题记录」 | **点它直接新开整页审查**（不做右侧分页）：左边会话列表（`全部 / 收藏` 切换；收放按钮按**动作方向**给箭头——展开态 `<` 往左收、收起态 `>` 往右拉，右侧会话界面宽度自动跟随），右边整段作答历史 + **底部追问输入框**；行内 `✎` 重命名、`×` 删除（居中确认框）——抽屉那套交互原样复制进来，抽屉本身不变 |
| 会话里的截图 | **不可点**（两处都禁用了点击）：`data URL` 开新标签就是空白页，看细节用 Edge 自带的页面缩放 |
| 设置里的「自动核实」 | **默认开**：答完自动联网核实。关掉后不自动跑，回答里出现「🔍 核实一下」按钮，点它才开始核实（按钮随即消失） |

## 回答流程（先快再准）

1. **阶段A 直接作答**：一次视觉调用（`reasoning_effort=none` 让思考归零，实测首字 ~1.8s），
   输出 `题号 / 答案 / 一句话解析 / CERT 自评`，边生成边渲染。
   会话**建出来就有真标题**：`日期-时分`（如 `0927-1432`，一定拿得到，绝不停在占位）；
   题号一解析出来就**立刻异步起名**成 `0927-第7题`（图上没题号则让模型给 ≤20 字大意 → `0927-导数求值`），不阻塞作答。
   名字不满意可点列表行的 `✎` 手改。
   - **`<<ok>>` 守卫**：`CERT` 行写 `<<ok>>`（纯计算/教材常识）→ 直接跳过核实，UI 标 `⏭ 已跳过 · 初答自评确定`；
     写 `<<check>>` 或没给 → 进阶段B。
   - **答案与解析必须同向**：协议把 `WHY` 排到 `ANS` 前面并明写一致性；落库前 `contradicts(ans, why)` 再自检一遍
     （只对 `A（对）`/`B（错）` 这类判断题判），一旦「答案说对、解析说错」就把 `<<ok>>` 跳过捷径作废、强制进阶段B，
     日志留一行 `初答自检矛盾`。
2. **阶段B 联网核实**（会思考，思考过程**显示**在「思考」块里）：带 `web_search` / `web` 两个工具的循环
   （默认 ≤5 轮，轮次用光会强制收尾拿结论），检索关键事实后给出
   `✅ 与初答一致` 或 `❌ 初答有误 + 正确解析`（**带来源**）；判 `FIX` 时它给的 `ANS` 行会**覆盖答案行**，
   保证答案行与最终结论一致。

> 实测效果：一道「Edge 最新主版本号」的题，初答给 `无` / `138`，核实阶段检索 Microsoft Learn 后
> 一致纠正为 `154（154.0.4258.37，2026-09-24）`；一道纯求导题，初答自评 `<<ok>>` 直接跳过核实。
3. **通知**：答完**总会在右下角弹 toast**（它是与抽屉同级的组件，不挂在抽屉里 → 抽屉收起时照样弹；
   从右向左滑入，3.6s 消失，点击跳该会话）；抽屉收起 / 页面切走一律算「没在看」→ 另发**系统通知**并亮红点。
   （系统通知的图标必须写绝对 URL，相对路径会被拒，详见 `docs/design.md` 排错表。）

**框选阶段**：宽高**都**低于 60×40（CSS px）判为「框太小」→ 不建会话、不发送、留在截图状态让你重拖；
要截细长条只要有一边过线就放行。滚动页面会取消框选（滚动穿透 + 重截回灌的方案实测会卡，已回退）。

**排错**：设置页 →「日志」页（环形 300 条、4 秒自动刷新、可复制/清空），
框选 / 起名 / 回答 / 镜像四条链路的事件都在里面。

## 安装

1. Edge 打开 `edge://extensions/` → 打开「开发人员模式」→「加载解压缩的扩展」→ 选中本目录。
2. 快捷键默认 `Alt+S`（S=Spore，避开与其它扩展的冲突）；若没绑，去 `edge://extensions/shortcuts` 设置，或者直接在页面里按 `Alt+S`（扩展同时监听了页面按键，两条通道 400ms 内自动去重）。
3. 首次使用进 `⚙` **主页**填 **API Key**（仓库不带默认 key），点「测试连接」确认模型可达
   （模型默认 `deepseek-v4-flash-vision-exp`），再点「选择目录」指定磁盘镜像目录（静默写盘，之后不再弹下载列表）。
4. **改了代码要两步重载**：`edge://extensions` 点扩展卡片上的「刷新」，再刷新页面 —— content script 只在
   页面重新加载时换新，SW 只在扩展重载时换新（否则你看到的还是旧字体/旧行为）。

> `chrome://`、Edge 内部页、扩展商店页不允许截屏与注入，Alt+S 在这些页面无效（浏览器限制）。

## 目录结构

```

options.html|js          设置页（搜题记录首块 + 应用设置四卡）
review.html              整页「搜题记录 / 题目审查」：左会话列表（可收起、全部/收藏）+ 右作答历史
src/
  sw.js                  截图、裁剪、会话调度、并发回合、通知与红点、磁盘镜像
  lib/
    llm.js               OpenAI 兼容 SSE 客户端（tool_calls 装配、瞬时错误重试、abort）
    tools.js             web_search（引擎链 ddg→bing→brave + 三道闸；bing 腿 RSS 主 + HTML 回落）/ web（正文抓取）
    store.js             会话存储（chrome.storage.local）+ Downloads 镜像
    agent.js             两阶段作答 + 异步起名 + 追问（追问带同一套检索工具循环）
    md.js                markdown/转义纯函数（抽屉与整页审查共用一份语义）
  content/
    drawer.js            抽屉（Shadow DOM）：消息流、会话列表、toast、滚动策略
    overlay.js           框选层（冻结帧 + 遮罩 + 尺寸标签）
  review.js              整页审查的列表/筛选/历史渲染
```

## 关键实现约定

- **滚动**：只有用户动作会移动视图（发问/切会话/点 ↓/首次展开）。发问与开始作答时把题目**定位到顶部一次**，之后流式期间绝不跟随——用户停在哪就固定在哪。
- **截图裁剪**：先抓原始帧再注入框选层（层不会进截图）；框选期间抽屉先隐藏。裁剪坐标按 `截图像素 / 视口 CSS px` 换算（多屏、150% 缩放都对），JPEG 长边 ≤1600、q0.82。
- **数据**：全部存 `chrome.storage.local`（`spore.index` 索引 + `spore.sess.<id>` 一 key 一会话）。
  磁盘镜像是设置页里的**一个独立模块**（总开关关掉，下面整组隐藏），三档递进：
  1. **选了静默目录** → File System Access `createWritable()` 直写，**零弹窗**（推荐）；
  2. **没选目录** → 默认回落到下载（默认位置就是 `Downloads/Spore/sessions/<日期>/`，Edge 会弹下载列表）；
  3. 总开关关掉 → 完全不落盘。
  授权失效（浏览器重启会重置）→ 设置页标红提醒重选。
- **回合状态**：`store.beginTurnSession()` 把在途会话对象设成唯一事实源，所有写入方（心跳、起名、
  收尾）拿到同一份引用 —— 否则各自「重读再写回」会用陈旧副本把答案覆盖没（实测踩过）。
- **并发**：一个会话一个 `AbortController`，互不阻塞；端口每 5s 上报「在看哪个会话」延长 SW 生命周期，
  SW 被杀后残留的 `answering` 状态在下次启动时判为「已中断」并亮红点（可点 `↻` 重跑）。
- **异步起名**：改名与在途回合会互相覆盖（在途的 `sess` 还攥着旧 title），所以 `store.js` 用一份
  `titleOverrides` 让所有写入统一带上定稿标题。
- **存储写入**：流式期间按 1.2s 节流落盘，避免撞上 storage 的写频率配额。

## 已知限制

- **检索**：引擎链与三道闸同步自 Fungi spec §71（2026-09-28）——`duckduckgo → bing → brave`，
  空页/节流页重试一次、结果必须含查询实词（诱饵页不返回）、失败逐腿报错
  `ERROR: Search failed (duckduckgo timed out; bing HTTP 429)`；全空回 `(no results for '…')`。
  走哪套引擎由设置页「**检索代理**」字段声明（填了 = 有代理 → ddg 打头；留空 = 只走 bing）：
  扩展没法只给自己的检索换代理，浏览器本身就按系统代理路由，这个开关等价于 Fungi 读注册表的那道判断。
  解析改版会导致解析失效 —— 腿的实现与解析都在 `src/lib/tools.js`（`searchDdg`/`parseRss`/`parseHtml`/`searchBrave`）。
- 阶段B 判 `FIX` 时会用它给的 `ANS` 行覆盖答案行，但不会重排版面。
- 磁盘镜像写的是下载目录，不是仓库目录（浏览器扩展无法直接写任意路径）。
